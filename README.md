# java-lotto-precourse
> 로또 게임

## 📋 기능 목록

### 1. 로또 번호 생성 및 검증
- [x] 1~45 범위의 숫자 6개로 구성된 로또 생성
- [x] 로또 번호 중복 검증
- [x] 로또 번호 개수 검증 (6개)
- [x] 로또 번호 범위 검증 (1~45)

### 2. 로또 구매
- [x] 구입 금액 입력 받기
- [x] 구입 금액 검증 (1,000원 단위)
- [x] 구입 금액만큼 로또 자동 발행
- [x] 발행한 로또 수량 및 번호 출력

### 3. 당첨 번호 입력
- [x] 당첨 번호 6개 입력 받기 (쉼표로 구분)
- [x] 당첨 번호 유효성 검증
- [x] 보너스 번호 입력 받기
- [x] 보너스 번호 유효성 검증
- [x] 보너스 번호와 당첨 번호 중복 검증

### 4. 당첨 결과 계산
- [x] 구매한 로또와 당첨 번호 비교
- [x] 일치하는 번호 개수 계산
- [x] 보너스 번호 일치 여부 확인
- [x] 당첨 등수 판별 (1등~5등)

### 5. 당첨 통계 출력
- [x] 등수별 당첨 개수 출력
- [x] 총 수익률 계산 및 출력 (소수점 첫째 자리 반올림)

### 6. 예외 처리
- [x] 잘못된 입력 시 에러 메시지 출력
- [x] 에러 발생 시 해당 부분부터 재입력
- [x] IllegalArgumentException으로 예외 처리
